1. Поиск клиник (Yandex MapKit)

ClinicSearcher & LocationHelper

MapKit SDK

Используется SearchFactory для поиска организаций по категории «ветеринарная клиника» в заданном гео-радиусе от текущих GPS-координат пользователя с автоматическим геокодингом и кешированием маркеров. 

class ClinicSearcher(private val searchManager: SearchManager) {
    fun searchNearbyClinics(userPoint: Point, onResult: (List<Clinic>) -> Unit) {
        val searchOptions = SearchOptions().apply {
            searchTypes = SearchType.BIZ.value
            resultPageSize = 25
        }
        searchManager.submit(
            "ветеринарная клиника",
            VisibleRegionUtils.toPolygon(userPoint, radius = 7000.0),
            searchOptions,
            object : SearchListener {
                override fun onSearchResponse(response: Response) {
                    val clinics = response.collection.children.mapNotNull { it.toClinic() }
                    onResult(clinics)
                }
                override fun onSearchError(error: Error) { /* Handle gracefully */ }
            }
        )
    }
}

2. Экстренный режим SOS (24/7)

MapScreen & MapViewModel фильтрация

Emergency SOS

По нажатию на кнопку SOS стейт мапы мгновенно переключается: отсекаются все закрытые заведения, оставляя только isOpenNow == true с функцией звонка в реанимацию в один тап. 

// В MapViewModel: реактивная фильтрация открытых стационаров
val activeClinics: StateFlow<List<Clinic>> = combine(
    _allClinics,
    _isSosModeEnabled
) { clinics, isSos ->
    if (!isSos) clinics
    else clinics
        .filter { it.workingHours.isOpenNow(currentTime = Instant.now()) }
        .sortedBy { it.distanceFromUserInMeters }
}.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), emptyList())

3. Локальный OCR-анализ состава

Tesseract Engine & Preprocessing

Tess-Two / NDK

Изображение с камеры переводится в бинарный контраст (бинаризация Оцу), выравнивается угол наклона и подается в C++ движок TessBaseAPI с русской и латинской моделями. 

class TesseractOcrEngine(context: Context) {
    private val tessApi = TessBaseAPI().apply {
        val trainedDataPath = context.filesDir.absolutePath + "/tessdata"
        init(trainedDataPath, "rus+eng")
        pageSegMode = TessBaseAPI.PageSegMode.PSM_AUTO
    }

    suspend fun extractComposition(bitmap: Bitmap): String = withContext(Dispatchers.Default) {
        val preprocessed = ImageFilters.toGrayscaleAdaptiveThreshold(bitmap)
        tessApi.setImage(preprocessed)
        return@withContext tessApi.utF8Text ?: ""
    }
}
